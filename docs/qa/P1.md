## Extra checks done

- ✅ All 33 default feeds fetched live (`cargo test --test live_feeds -- --ignored`). Two feeds timed out with rustls; switching to native TLS fixed it.
- ✅ Ranking tuned on live data. Before the tuning, DEV Community posts filled the top 15; now quality blogs and news lead (SPEC §7.6 note).
- ✅ Non-English items are skipped (Spanish DEV posts appeared in the live data).
- ✅ Release bundle builds: `Tech English.app` is 9.7 MB.
- ✅ The main window is created on demand and destroyed on close, which saved about 85 MB of idle memory (checked: only the widget window exists at startup, and a second launch with the widget hidden creates the 1000×700 main window).
- ⚠️ A full fetch takes about 29 s (network-bound). This is over the 12 s budget; see `docs/perf.md`.

## Known limitations (P1)

- Clicking a notification only brings the app forward (a Tauri desktop limitation; see the P1 dev spec §4.10).
- "Read" opens the browser. The in-app Reader arrives in P2.
- In `tauri dev`, macOS may not show notifications. Test notifications with the bundled app.
