## Bugs found and fixed during P2

- **Qwen3.5 returned empty answers.** It's a "thinking" model and spent the whole budget thinking. The app now always sends `enable_thinking: false` (found in the spike).
- **Chat question shown twice.** The answer could finish (and reload the chat) before the send call returned. Fixed by de-duplicating by message id. Found in the browser preview.
- **"(not from the article)" added to answers that were from the article.** Prompt wording tightened.
- **Stop could still add one more chunk of text.** `select!` is now `biased` toward cancellation.
- **Stopping the engine at Quit could panic** (`block_in_place` outside a worker thread). Now uses `spawn_blocking`.
- **Homebrew had no llama.cpp build for this Mac.** The app now also finds the official llama.cpp build in its data folder.
