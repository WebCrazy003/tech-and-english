## Found and fixed during P4

- **The dictionary returns the first word for a phrase** ("on the fly" → "fly"). Without a check, the popup would show the meaning of "fly". The phrase is now looked up in the PHRASES section, or shown as "Not in the dictionary".
- **The planned parser format was not the real one.** Written again from 8 real outputs (syllables after the headword, "•" sub-senses, examples after ":", subject labels, a second part of speech).
- **The AI copied the prompt's example** ("run inference") into the collocations of unrelated words. The example now uses another word.
- **WKWebView voice IDs** carry "enhanced"/"premium", not the names; the robotic "eloquence" voices and macOS novelty voices ("Bubbles", "Bad News"…) were offered. Filtered, and the default prefers Premium/Enhanced.
- **Quiz keys crashed** when the key event target was not an element (seen in the preview test). Made safe.
- **Layout:** the missed-words list on the result page squeezed words into a narrow column; the edit form's fields ran past the card; inputs without a `type` and textareas had no app style.
- **Safari may garbage-collect a speaking utterance** so "end" never fires: a reference is now kept while speaking.
