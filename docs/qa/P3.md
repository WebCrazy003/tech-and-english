## Bugs found and fixed during P3

- **The spec formula could not pass its own test titles.** A plain "How to …" title scored 0.25 (< 0.5). The first title pattern now counts 0.50 (SPEC §7.11 updated).
- **"Training in" / "classes in" would block real tutorials** ("Distributed training in JAX", "Data classes in Python"). Spam now needs a place name or a strong phrase.
- **The migration added the 9 new sources to fresh installs too**, before onboarding. It now only adds them when the user already has feeds.
- **Old articles had no learning score** after the upgrade, so Explore › Learning only and the lesson pool missed them. Now backfilled once at start.
- **Medium pages return HTTP 403** to the app. The Medium feed URL is now tried directly.
- **Commit feeds on GitHub pages** were valid Atom feeds. They are skipped now (commit messages are not articles).
- **"Story + lesson ready" did not fit** the 180 px pill. The pill is 200 px now.
- Hacker News showed a "Learning" switch. It is hidden for HN now.

## Known gaps (not blocking)

- On a first fetch, only ~6 articles match Data Engineering as learning material. The pool grows each day (60-day window). Adding keywords that match your roadmap (e.g. `SQL`, `PostgreSQL`, `data modeling`, `pandas`, `Docker`) or turning on Learn for Databases/Python gives more lessons.
- Some learning-source articles have no pattern words in the title or description (e.g. "How GRPO Trains Small Language Models"), so they score 0.35–0.45 and are not lessons. An LLM check could help later (dev spec §0, out of scope).
- The lesson topic chip on Today is read from the "why" text.
