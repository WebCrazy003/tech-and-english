## Final performance run (dev spec §7)

`docs/perf.md` › "v1.0.0". Every SPEC §16 row is listed. Idle memory first **missed** the budget (262–268 MB vs 250 MB); the cause (one large regex per topic keyword) was found and fixed, and the final run is 150 MB (Standard) / 182 MB (Hibernate). One old miss remains: a fetch cycle takes about 16 s (budget 12 s, background work).
