## Found and fixed during P5

- **`serde_json` sorted the schema keys**, which would put `correction` before `reply` and break streaming → `preserve_order`.
- The tutor put **only the changed word** in `correction.original/corrected` → prompt: whole sentences.
- The tutor wrote "Please say: …" but left `correction` empty, or set `ask_repeat` without "Please say" → local reconcile + appended sentence.
- Live: the tutor "corrected" an earlier mistake after the learner had already said it right → dropped when the learner's sentence equals the corrected one.
- `scrollIntoView()` returns a Promise in new WebKit/Chromium; returning it from `useEffect` crashed the session page → braces.
- Removing old history turns makes llama-server re-read everything (≈ 4 s) and `--cache-reuse` is not supported for Qwen3.5 → the history is trimmed in one step (12 → 3 exchanges).
